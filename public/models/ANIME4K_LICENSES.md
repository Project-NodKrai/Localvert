# Anime4K v4 S/M/L 2× browser runtime

Anime4K v4.0.1 WebGL shader implementation: monyone/Anime4K.js, MIT license.
Original Anime4K shaders and model architecture: bloc97/Anime4K, MIT license.

Install via pinned local package `anime4k.js@1.1.9`; no user images are sent to any third-party server.
This model uses the GPU shader backend, not the TensorFlow.js or ONNX inference path.

Sources:
- https://github.com/monyone/Anime4K.js
- https://github.com/bloc97/Anime4K
